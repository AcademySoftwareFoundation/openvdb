vdb_tool:

  New Features:
  - Added action "-diagnose", which runs OpenVDB's built-in diagnostics (tools::checkLevelSet for level sets, tools::checkFogVolume for fog volumes, NaN/infinity checks for other float grids) on one or more VDB grids, printing OK/FAILED with details. "checks=N" limits how many checks run, and "fatal=true" throws on any failure to abort the pipeline.
  - Added action "-stats", which prints background value, active-voxel min/max/mean/stddev, and (for Float level sets) surface area and enclosed volume in a column-aligned table. Complements "-print" (structural metadata) by covering value-derived information.
  - Added action "-histogram" (alias "-hist"), which prints an ASCII bar chart of the distribution of active values, with "bins", "cols", "min"/"max" and "log=true" options. Vector grids are binned by magnitude, and degenerate cases (no active voxels, constant grid, empty range) are reported explicitly.
  - Added actions "-multiply" (alias "-mul") and "-divide", which compute the per-voxel product and quotient of two scalar VDB grids via tools::compMul/compDiv, complementing "-min", "-max" and "-sum".
  - Added action "-rename", which renames a VDB grid and/or Geometry on the stack by age index via the "vdb"/"geo" options (at least one required). Both may be given together to assign the same "name" to a grid and a geometry in one call.
  - Added action "-swap", which swaps two VDB grids and/or two Geometry entries via comma-separated age pairs (e.g. "vdb=0,1"), useful for reordering the stack before non-commutative CSG operations like "-difference". The swap is O(1) and copies no data.
  - Added action "-copy", which deep-copies one or more VDB grids and/or Geometry (via "vdb"/"geo" age lists or "*" for all) onto the top of their respective stacks, validating all indices up front so an out-of-range one fails cleanly with no partial copies. An optional "prefix" is prepended to each copy's name, useful when branching a pipeline.
  - Added action "-files", a control-flow scope (closed by -end) that iterates over files in a directory, binding each match to "{$file}"; "recursive=1" descends into sub-directories. Matches are filtered by "extension", "include"/"exclude" patterns, and "min_size"/"max_size".
  - Added action "-mesh2udf", which converts a polygon mesh or soup into an unsigned distance field without requiring watertight or consistently oriented input. Resolution is set via "dim" or "voxel", "width" controls the narrow-band half-width, and the transform can instead be inherited from an existing grid via "vdb".
  - Added action "-quad2tri" (alias "-q2t"), which triangulates every quad face in a mesh via a naive fan from vertex 0, assuming each quad is planar and convex (not verified). Existing triangles are left untouched.
  - Added actions "-vol2mesh" (alias "-vdb2mesh") and "-fog2mesh", which extract a polygon mesh from a scalar or fog-volume VDB grid respectively by meshing an iso-surface ("iso" defaults to 0 and 0.5 respectively). Both support adaptive meshing via "adapt" and an optional "mask" grid (with "invert=true" for its complement) to restrict the meshed region.
  - Added action "-slice", which writes PPM images of axis-aligned planar slices through a scalar VDB grid at normalized positions given by "X"/"Y"/"Z" (default 0.5, the mid-plane), so one invocation can emit many slices. "scale" sets image size and "force" recomputes true min/max for color mapping instead of assuming level-set/fog-volume ranges.
  - Added action "-img2mpeg", which converts image files to an mpeg movie when vdb_tool is built with ffmpeg.
  - Added action "-log", which mirrors the tool's diagnostic output (clog/cerr/cout) to a log file for the remainder of the pipeline, with a self-describing header (date, version, command line) and unit-buffered writes for real-time "tail -f". "append" and "tee" (default true, also echo to terminal) control the output mode.
  - Added action "-sdf2udf", which converts a signed distance field into an unsigned distance field by taking the absolute value of every voxel, changing the grid class to UNKNOWN since the sign is discarded. Useful when only proximity to the surface matters, not which side you're on.
  - Added actions "-forAllValues"/"-forOnValues"/"-forOffValues", which apply a math kernel (RPN or infix, via the Calculator) to all, active, or inactive grid values, binding "v" to the voxel value and other identifiers to scalars from earlier in the pipeline. Stencil kernels like "v(1,0,0)-v(-1,0,0)" read neighbor voxels via a per-thread accessor, and "use="/"vdb=" accept comma-separated lists so a kernel can read from multiple grids in one pass.
  - Added the Calculator class, a compact bytecode interpreter for math expressions (RPN, infix, or multi-statement with assignment) over named float inputs, and the "-calc" action that runs a Calculator expression at command-line scope. Both accept a bare positional kernel in addition to "kernel="; "-calc" also writes intermediate/trailing-LHS values back to the Processor's string memory so later actions can read them by name.
  - Added actions "-switch" and "-case", a multi-way control-flow construct (closed by -end) analogous to -if: each "-case key=<value>" inside a "-switch on=<selector>" scope runs only if its key matches, with "key=*"/"default" as a catch-all. Keys and the selector both accept {...} template expressions.
  - Added the optional action "-ax", which runs an OpenVDB AX expression over one or more grids (gated behind CMake option OPENVDB_TOOL_USE_AX, off by default), complementing the built-in Calculator with the full AX language and point-attribute access. Code may come from an inline "code=" string or a "file=", and "bindings=axname:gridname,..." remaps AX names to actual grid names.
  - Added triangulation of N-gons to Geometry::readOBJ and Geometry::readSTL, assuming they are convex and planar.
  - Added the string-similarity helpers vdb_tool::levenshtein and vdb_tool::fuzzyMatch to power "Did you mean ...?" suggestions for mistyped action names, option names, and Calculator identifiers/functions. The same routine backs matching in the Parser, Action and Calculator so suggestions stay consistent.

  Improvements:
  - Every "vdb"/"geo" option now also accepts grid/geometry names in addition to stack ages (e.g. "vdb=density"), resolved to ages on every read including inside loop bodies. An unmatched or ambiguous name reports a clean error rather than silently expanding.
  - Action "-read" gained optional support for OpenUSD (.usd/.usda/.usdc/.usdz meshes and points, enable with VDB_TOOL_USE_USD), glTF/binary glTF (.gltf/.glb triangle meshes via tinygltf, enable with VDB_TOOL_USE_GLTF), and ASCII XYZ point files (.xyz, one point per line, also readable from stdin). Each of these minimal readers skips unsupported features (e.g. instancing, materials, non-triangle primitives) rather than failing outright.
  - Action "-mesh2ls/mesh2sdf" now supports generation of asymmetric narrow bands.
  - Improved error reporting and handling throughout vdb_tool: unsupported actions/options and other failures now print clearer diagnostic messages, and the tool recovers from non-fatal errors instead of aborting the whole pipeline.
  - Actions can now have multiple names (or aliases), e.g. "-read", "-import", "-load", "-i".
  - Added cutoff option to "-ls2fog" action.
  - Improved parsing of configuration files (tabs and trailing comments are now ignored).
  - Improved unit-tests and Doxygen documentation for all files related to the vdb_tool.
  - Reformatted "-print" as a column-aligned Unicode table reporting only structural metadata (age, name, type, class, dim, active voxel count, voxel size, memory, and at level=1 the bounding box and per-level node counts); value-derived info (background, min/max, area, volume) moved to the new "-stats" action. BREAKING CHANGE: the old level=2 (which reported that value-derived info via "-print") was removed, so scripts passing level=2 must switch to "-stats".
  - Action "-if" now accepts infix and RPN test expressions via the Calculator, in addition to 0/1/true/false literals and {...} expressions, e.g. "-if 'n > 0'".
  - The Calculator now supports compound-assignment operators (+=, -=, *=, /=, %=), desugaring to "x = x <op> (rhs)" with the right-hand side parenthesized to preserve precedence. A compound operator with a non-identifier target still reports an invalid-assignment-target error.
  - The Calculator now accepts OpenVDB AX-style attribute/grid sigils (e.g. "f@sphere" or "@density"), making simple scalar kernels portable between -forValues and -ax, including neighbor access by grid name. This is a one-directional convergence of the common scalar subset; AX-only features remain exclusive to -ax.
  - The expression-based actions "-calc", "-forAllValues/forOnValues/forOffValues" and "-ax" gained a "file=" option that reads the kernel/expression/code from a file instead of the inline option; "file" takes precedence if both are given.
  - Actions "-for", "-each" and "-files" gained a "quiet" option (default false) that suppresses the per-iteration "Processing: ..." line for that loop without silencing the rest of the pipeline.
  - Action "-log" now also redirects std::cerr and std::cout (not just std::clog) so warnings and "-print" output land in the log file too, with unit-buffered writes, a self-describing header, and new "append"/"tee" options.
  - Renamed the polygon-soup-to-level-set action from "-soup2ls" to "-shrinkwrap" and "-soup2offset" to "-mesh2offset" (matching the "-mesh2ls"/"-mesh2udf" convention), now always built (no longer gated by VDB_TOOL_USE_SHRINKWRAP). The underlying class/functions moved from the core library to openvdb_cmd/vdb_tool/include/ShrinkWrap.h as ShrinkWrap/shrinkWrap(); the old names remain as deprecated aliases that print a one-line warning.

  Fixes:
  - Fixed "-clear" erasing requested ages one at a time, which could shift ages and partially delete the stack given several ages; all requested ages are now resolved and de-duplicated up front.
  - Fixed issues in Geometry::readSTL so it works on all files in Thingi10K, and fixed a bug reading ASCII PLY and OFF files with normals.
  - Fixed several typos in the documentation of vdb_tool.
  - Fixed vdb_tool::uuid to generate a proper 36-character RFC 4122 v4 UUID, and fixed corner cases in getFile/getName/getPath/getExt/replacePath/replaceExt by adopting <filesystem>.
  - Made halfWidth parameter configurable in distanceFieldToSDF(): float in voxel units (default 3.0, matches meshToVolume pattern), with proper rounding via math::RoundUp() for dilation iterations.
  - Refactored Geometry::readPLY() to use Geometry::triangulate() for N-gon triangulation (both binary and ASCII formats), matching the approach used by readOBJ() for consistency and code reuse.
  - Consolidated error handling across all 29 Tool action methods into a centralized handler in Parser::run(), eliminating 253 lines of duplicated try/catch code while preserving existing error-handling behavior and public APIs.
