NanoVDB:

  API Changes:
  - The GPU tools build into nanovdb::cuda::Buffer<std::byte> by default, in place of the removed dual-space buffer: a call that does not pass a buffer now returns a GridHandle<cuda::Buffer<std::byte>> that holds its grids on the device only. Read the grids with deviceGrid(), and use cuda::copyTo to copy them to a host handle. This covers pointsToGrid, voxelsToGrid, PointsToGrid, IndexToGrid, indexToGrid and the device createNanoGrid, addBlindData, MeshToGrid and its distance sidecar, DilateGrid, MergeGrids, PruneGrid, RefineGrid, CoarsenGrid, buildVoxelBlockManager, and the deprecated cudaPointsToGrid, cudaVoxelsToGrid, cudaIndexToGrid, cudaCreateNanoGrid and cudaAddBlindData. DistributedPointsToGrid builds into cuda::Buffer<std::byte, cuda::ManagedResource> by default.
  - Removed the dual-space buffers deprecated in 13.1 and 13.2: cuda::DualDeviceBuffer, cuda::DualUnifiedBuffer and their aliases cuda::DeviceBuffer, cuda::UnifiedBuffer and CudaDeviceBuffer, together with BufferTraits::hasDeviceDual; a GridHandle over a buffer whose BufferTraits still declares hasDeviceDual fails to compile. The headers nanovdb/cuda/DeviceBuffer.h, nanovdb/cuda/UnifiedBuffer.h and nanovdb/util/cuda/CudaDeviceBuffer.h remain for one release as #error messages naming the replacement.
  - Removed the dual-space handle surface: GridHandle::deviceUpload, deviceDownload and deviceData(int), NodeManagerHandle::deviceUpload and deviceDownload, the dual-space overloads of VoxelBlockManagerHandle::deviceFirstLeafID and deviceJumpMap, the dual-space overloads of cuda::createNodeManager, cuda::mergeGridHandles and cuda::splitGridHandles, and the older cudaCreateNodeManager, mergeDeviceGrids and splitDeviceGrids, which only accepted dual-space buffers. Use cuda::copyTo, cuda::createNodeManager(deviceGrid) or cuda::createNodeManager(deviceGrid, resource), and the single-space cuda::mergeGridHandles and cuda::splitGridHandles.
  - Removed cuda::detail::HandleFactory; use GridHandle::adopt and GridHandle::metaData.
  - Removed the static cuda::DeviceResource::allocateAsync and deallocateAsync; use the instance methods allocate_async and deallocate_async.
  - Removed cuda::Buffer::resize(count, stream); use resize(stream, count). Removed cuda::Buffer::clear and cuda::BufferView::clear; use destroy.
  - Memory resources must provide operator==: cuda::Buffer and cuda::ResourceRef over a resource without it fail to compile, where 13.2 warned.
  - VoxelBlockManagerHandle::hostFirstLeafID and hostJumpMap are unavailable for a device-only buffer, like GridHandle::data. DistributedPointsToGrid::getHandle and getBuffer reject, at compile time, a buffer that is not both host- and device-accessible.
