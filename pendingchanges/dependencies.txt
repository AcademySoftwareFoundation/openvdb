OpenVDB:
  New features:
  - Added openvdb::logging::Sink, addSink, removeSink and findSink to route log messages into a host application. A ConsoleSink writing to std::cerr is installed by default.

  Improvements:
  - Added -debug, -info, -warn, -error and -fatal flags to vdb_ax, vdb_lod, vdb_print, vdb_render and vdb_view.

  API Changes:
  - Removed openvdb.setProgramName (Python) and logging::setProgramName (C++).

  Build:
  - Minimum versions now track VFX Reference Platform CY2025: MSVC 19.36, OpenEXR 3.3, TBB 2021, Python 3.11, nanobind 2.5.0, GoogleTest 1.12. The recommended GCC is 14.2.
  - Dropped support for TBB 2020.3.
  - Removed the Log4cplus dependency. The USE_LOG4CPLUS CMake option is deprecated and has no effect.
  - CMake now fails if the nanobind version is below the minimum.

OpenVDB AX:
  Improvements:
  - Removed the legacy code for LLVM versions older than 16, including codegen/LegacyIR.h.

  Build:
  - The minimum LLVM version is now 18.0.0.

Houdini:
  Improvements:
  - Log messages can be forwarded to the Houdini Universal Log under the source name "OpenVDB". Error and Fatal messages are reported as warnings with a prefix.

  API Changes:
  - startLogForwarding, stopLogForwarding and isLogForwarding no longer take an OP_OpTypeId.
  - Log forwarding is no longer started automatically. Enable it with the new OPENVDB_HOUDINI_LOG_FORWARDING CMake option or by calling startLogForwarding.

NanoVDB:
  Improvements:
  - CI now uses the 2027 VFX platform images.

  API Changes:
  - The GridHandle buffer move constructor is now a single non-template constructor. Constructing a GridHandle from anything other than a BufferT rvalue is now a compile error.

  Fixes:
  - Fixed a link failure with clang when nvcc uses g++ as the host compiler.
