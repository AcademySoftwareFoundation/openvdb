NanoVDB:
  New Features:
  - Added doc/nanovdb/TEACHME/, an interactive tutorial for the NanoVDB user API.
    The lesson documents are written to be loaded by an LLM coding agent, which
    then teaches the API interactively to a developer who is new to NanoVDB.
    Covers sparse-grid foundations, GridHandle and IO, ReadAccessor, NodeManager,
    math/sampling/HDDA, GPU kernels, the GPU grid builders (PointsToGrid and
    MeshToGrid), topology operators and data re-homing, IndexGrid and
    VoxelBlockManager, and OpenVDB/NanoVDB conversion. Ships with a one-page
    cheat sheet and a GPU level-set ray-marching capstone project.

  Build:
  - Added a compile-only test harness for the TEACHME tutorial. It extracts every
    C++/CUDA code block from the lesson documents and compiles them against the
    real NanoVDB headers, and validates the header references in the prose, so a
    NanoVDB API change that invalidates the tutorial is caught rather than
    silently rotting. Runs in CI when either the NanoVDB headers or the tutorial
    change.
