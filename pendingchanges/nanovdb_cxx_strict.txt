NanoVDB:
  Fixes:
  - Fixed tools::build::ValueAccessor::setValue on bool grids, which stored true regardless of the value once the leaf node was cached.
  - NANOVDB_OFFSETOF now uses the standard offsetof instead of subtracting null pointers, which is undefined behavior.

  Build:
  - NanoVDB, its unit tests and its command-line tools now build with OPENVDB_CXX_STRICT=ON under Clang/AppleClang. Fixed implicit-conversion, unused-parameter, unused-function and deprecated-copy warnings under the project's strict warning configuration, which includes -Wconversion -Werror -Wno-sign-conversion.
  - The static functions in CNanoVDB.h and io/IO.h are now static inline.
  - -Winvalid-offsetof is suppressed privately for the NanoVDB layout-test target under Clang/AppleClang. The existing GCC suppression is unchanged.
  - The macOS NanoVDB CI jobs now build with OPENVDB_CXX_STRICT=ON.
