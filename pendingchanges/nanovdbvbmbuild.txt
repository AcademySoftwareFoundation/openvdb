NanoVDB:
  Improvements:
  - Reworked the CUDA VoxelBlockManager build to launch one thread per leaf over the
    dense leaf array instead of one thread per lower-node child slot gated on the
    childMask, and removed the synchronous device read of the node count from the
    build into a pre-allocated handle by caching the leaf count in the handle. Builds
    through a handle are now fully stream-asynchronous and measured 1.6-2x faster;
    outputs are byte-identical.
    The cached count is a launch-sizing hint only: the kernel reads the authoritative
    leaf count from the device-resident tree and iterates with a grid-stride loop, so
    a stale cache cannot cause out-of-bounds access or wrong output.
  - Added tools::cuda::buildVoxelBlockManagerBatch, which builds the VoxelBlockManagers
    of a batch of grids into shared arrays with one memset and one kernel launch and
    no host synchronization. Each grid's slice is byte-identical to its single-grid
    build. Grids are described by VoxelBlockManagerBatchEntry records, read from a
    device array or produced by any device-callable entry source, so callers can derive
    them in the build kernel. Grids' block ranges may leave gaps between them.
  - Documented the VoxelBlockManager's topology preconditions: an OnIndex grid's leaves
    must each hold an active voxel and tile the value indices from 1 in leaf order, up
    to at least the VBM's lastOffset. The default lastOffset is activeVoxelCount, which
    also rules out active tiles. createNanoGrid meets them only with
    includeStats and includeTiles off. The CPU and CUDA builders now share one per-leaf
    routine, which asserts the preconditions in builds with assertions enabled.
  API Changes:
  - VoxelBlockManagerHandle gained an optional trailing leafCount constructor
    parameter and leafCount()/setLeafCount() accessors (defaulted; existing callers
    unaffected).
  - Added tools::isVoxelBlockManagerCompatible, which checks a host-accessible
    OnIndex grid against the VoxelBlockManager's topology preconditions, for the
    whole grid or up to a given lastOffset.
