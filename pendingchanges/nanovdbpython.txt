NanoVDB:

  New Features:
  - The NanoVDB Python bindings now mirror the C++ nanovdb::* surface. GridHandle and DeviceGridHandle are sequences of typed grids: len(handle), handle[i] and iteration, plus handle.grid(n) / deviceHandle.deviceGrid(n), return the typed grid class for any of the 24 GridTypes (18 more BuildTs than before, including the Fp4/Fp8/Fp16/FpN quantized grids, ValueIndex/ValueOnIndex/ValueMask and PointIndex); handles also support splitGrids, mergeGrids and copy. Grids expose GridMetaData and the blind-data API (reading and, via tools.CreateNanoGrid.addBlindData, authoring), ChannelAccessor for index-grid channels, tree/node/leaf walking, createNodeManager(grid) returning the typed NodeManager, and zero-copy grid.leafValues() NumPy views. tools.build.<T>Grid builds grids voxel by voxel in Python and bakes them with .to_nanovdb(). The tools module gains per-grid stats, validation and checksum, nine additional primitives, Fp*/Index/OnIndex conversion, sampler gradient/zeroCrossing and the host VoxelBlockManager. The wheel ships the C headers with nanovdb.get_include() and generated .pyi stubs. Bindings are generated from a single BuildT list (python/BuildTypes.def), and fourteen example scripts under nanovdb/python/examples are smoke-tested by a new ctest.

  API Changes:
  - The typed GridHandle accessors (floatGrid(i), doubleGrid(i), int32Grid(i), vec3fGrid(i), rgba8Grid(i), pointGrid(i) and the deviceXxxGrid(i) variants) are replaced by handle.grid(i) / deviceHandle.deviceGrid(i); the buffer= keyword is gone from nanovdb.io.readGrid(s), deviceReadGrid(s) and the tools.create* primitive factories, which choose their buffer by function or submodule (tools vs tools.cuda); nanovdb.math.cuda.sampleFromVoxels moved to nanovdb.tools.cuda.sampleFromVoxels and the math.cuda submodule is gone; bool(handle) is now equivalent to not handle.empty() instead of raising; repr(GridType.Float) is 'Float'.
  - Added a borrowing mergeGrids(const GridHandle<BufferT>* const*, size_t, pool) overload to GridHandle.h; the VectorT overload delegates to it and now returns an empty handle when the inputs hold no grids.
