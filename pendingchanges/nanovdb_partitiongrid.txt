NanoVDB:
  New Features:
  - Added tools::cuda::PartitionGrid, which splits the active voxels of an index grid in two by a leaf-indexed
    retain mask, the same input as tools::cuda::PruneGrid: output 0 is identical to PruneGrid with the mask and
    output 1 to PruneGrid with the complemented mask, built in one pass.

  Fixes:
  - Fixed tools::cuda::TopologyBuilder crashing when a non-empty source leaves no voxel in the output (e.g.
    tools::cuda::PruneGrid with an all-off retain mask); the output is now a valid empty grid.
