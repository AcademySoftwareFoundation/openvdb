OpenVDB:
  Bug Fixes:
  - Reading a PointDataGrid now throws an IoError, instead of reading or writing
    out of bounds later, when the file has an attribute byte count smaller than
    the attribute array, a page size that does not match its compressed data,
    voxel offsets beyond the end of the attribute arrays, or a pass count too
    small to read every attribute array.
    [Reported by Anthropic and Ada Logics]

  API changes:
  - Added compression::bloscValidateCompressedBytes() to check a Blosc header
    against the number of bytes read before decompressing.
